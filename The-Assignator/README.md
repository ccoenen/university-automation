# The Asignator

Assigns a random person to a random person.

`node index.js -m EAC-Text -p Vorname,email,EAC-Text spreadsheet-filename.ods`

Reads a list. Goes over every line of the list and finds a random entry from that list and prints an arbitrary number of fields for this (here: Vorname, email, EAC-Text). In this case here, we ensure that those lines have a particular column populated (here: EAC-Text).
